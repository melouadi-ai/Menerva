  Addresses in coil/input format (e.g. 00033, 00042, 00065) MUST be written 
  as strings in the JSON to preserve leading zeros: "00042" not 00042.
  Holding register addresses (e.g. 40001, 40006) are written as integers: 40001.

### ID: copy the MODBUS slave/device ID from the document. Default = 1 if not found.

### MODBUSREGISTRONOME: write only if the document assigns a name to that register address. Otherwise omit the key entirely.

IMPORTANT: 40000.0 IS dot notation — the ".0" means bit 0, not a decimal 
  number. Any register written as INTEGER.DIGIT (e.g. 40000.0, 40001.0) 
  is ALWAYS dot notation and qualifies for GROUP if conditions 2 and 3 pass.
  Never treat 40000.0 as the integer 40000 — they are different things.

### GROUP: write "Ingresso_digitale" ONLY if ALL THREE conditions are true:

  1. DOT NOTATION OR TWO-COLUMN CHECK:
     FORMAT A — dot notation: the register appears written as INTEGER.DIGIT
       in the source (e.g. 40000.0, 40000.1, 40001.3).
       NOTE: 40000.0 IS dot notation — ".0" means bit 0, NOT a decimal number.
     FORMAT B — two-column: the row has BOTH an Addr_INT column AND a N.Bit
       column present in the document (regardless of whether the values are
       integers with no dot).
     Either format qualifies for this check. Plain integers (40001, 33) with
     NO dot AND no N.Bit column → STOP. NO GROUP. Ever.

  2. SHARED REGISTER CHECK: At least 2 rows TOTAL (including this one)
     share the same base register (Addr_INT or dot-notation base).
     Example FORMAT A: 40000.0, 40000.1, 40000.2 → 3 rows share 40000 → ✓
     Example FORMAT B: Addr_INT=40013 appears in 6 rows → ✓
     Single occurrence only → STOP. NO GROUP.

  3. TYPE CHECK: DRIVERDATA = 2 (packed digital).
     Analog (0) or single digital (1) → STOP. NO GROUP.

  If any condition fails → omit GROUP key entirely.
  Do NOT write null or "". Simply do not include the key.

### SCALE:
  Electrical (V, mA): use STARTSCALE_EL / ENDSCALE_EL keys.
  Engineering (mg/Nm3, %, mBar, °C, Nm3/h, mg/m3): use STARTSCALE_ENG / ENDSCALE_ENG keys.

### HOURLYLIMIT / DAILYLIMIT: extract from "hourly avg. limit value" / "daily limit" columns. These are critical — never skip.

## PHASE 4 — BITINFO RULES
(Only for packed digital measures. Not present in every document.)

* MEASUREID: exact same value as MODBUSREGISTRO of the parent measure.
* BITNO: the digit after the dot (40001.8 → 8). Not incremental — copy each value exactly.
* BITNAME: copy verbatim from the Description column. NEVER TAKE IT FROM OTHER NOTES, OTHER COLUMNS OR ANYTHING ELSE. Never leave empty. BITNAME column ≠ TEXTON column.

### TEXTON / TEXTOFF — decision tree (stop at first match):

  CASE 1 — explicit "1 = <label>" in source:
    TEXTON = that label | TEXTOFF = "OFF" (or explicit "0=label" if present)

  CASE 2 — explicit "0 = <label>", no "1 = <label>":
    TEXTOFF = that label | TEXTON = infer from keyword table below

  CASE 3 — explicit "OK" written as state value (not inferred):
    TEXTON = "OK" | TEXTOFF = infer from keyword table (MUST NOT be "OK")

  CASE 4 — blank / empty / missing state value:
    TEXTON = infer from keyword table | TEXTOFF = "OFF"


  KEYWORD TABLE -usually "note" column- (scan BITNAME, ONLY IF THERE IS NOT THE LOGIC STATE/RANGE VALUE IN THE PROMPT, use first match):
    ALLARME / ALARM       → "Allarme"
    FAULT / GUASTO        → "Guasto"
    ANOMALIA / ANOMALY    → "Anomalia"
    MANUTENZIONE          → "Manutenzione"
    CALIBRAZIONE          → "Calibrazione"
    ZERO                  → "Zero"
    SPAN                  → "Span"
    BYPASS / BY-PASS      → "Bypass"
    VALVOLA / VALVE       → "Aperto"
    STATO / STATUS        → "Attivo"
    no match              → "Attivo"

  PROHIBITIONS:
    TEXTON ≠ TEXTOFF (never equal).
    "1 = label" value NEVER goes to TEXTOFF.
    Blank/empty state = CASE 4, not CASE 1.

EXAMPLE:
Tag	PLC internal	Description	Read / Write	DataType	Register Address	Logic State / Range	Units	Note	ModBus Addr
Check Cycle Polverimetro	R	bool	1.0	1 =		Check Cycle Attivo	40001.0

BITNAME = Check Cycle Polverimetro
TEXTON = Check Cycle Attivo
TEXTOFF = OFF

EXAMPLE N2:

Description             Logic State / Range             Note
Condizionatore 2 OFF    1                     =           ok

BITNAME = Condizionatore 2 OFF
TEXTON = OK
TEXTOFF = OFF

## PHASE 5 — FINAL RULES

* One JSON object per distinct IP (including placeholders). Order = document order.
* Variables of different IPs MUST NOT share the same station object.
* Packed digital → ONE measure entry per register; all bits go to bitinfo.
* Decimal commas → decimal dots (e.g. 706,54 → 706.54).
* All null values: write null (lowercase only — never "NULL" or "Null").
* Omit MODBUSREGISTRONOME and GROUP keys entirely when not applicable.
* WORD as counter/watchdog/heartbeat → analog measure, no bitinfo, no GROUP.
