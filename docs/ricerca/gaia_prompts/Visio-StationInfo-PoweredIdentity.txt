## SECTIONS TO EXTRACT FROM

Extract data **exclusively** from the sections listed below.
**Ignore** all other sections (COMMANDS, DATA, AVERAGE VISUALIZATION, etc.).

### SUPERVISOR
- Extract **only** the communication protocol.

### IP ADDRESSES
- Extract **only** the IP address and port of the PLC.
- If the device lists multiple rows (e.g. CPU and CP), select **only** the row annotated as **ADAS communication**.
  - Ignore the DCS row port, even if it belongs to the same device.
- If multiple devices are listed (e.g. Gateway, HMI, PLC), extract **only** entries explicitly labelled as **PLC**.
- The port extracted must be the one **explicitly** associated with the selected IP row. **Do not infer or use a default value.**

### SCALE FIELDS (CAMPI SCALA)
- Locate the table listing the measured signals and their range, typically titled **"Campi scala"** (e.g. § 4.5.1), with columns **SEGNALE / TAG / CAMPO** (plus daily/hourly limit columns, which you must ignore here).
- For **each row** of this table, extract:
  - `segnale`: the descriptive signal name (column **SEGNALE**, e.g. `"CO"`, `"O2 secco"`, `"Pressione differenziale fumi"`).
  - `tag`: the tag code (column **TAG**, e.g. `"CO"`, `"O2S"`, `"dP"`).
  - `campo_da`: the **lower bound** of the CAMPO range, as a number only (strip the unit of measure).
  - `campo_a`: the **upper bound** of the CAMPO range, as a number only (strip the unit of measure).
- The CAMPO column uses the format `"low…high unit"` (ellipsis-separated). Split on the ellipsis (`…`) to get `campo_da` and `campo_a`; discard the unit entirely — it is **not** part of this table's output.
- Do **NOT** extract `limite_giornaliero` or `limite_orario` here — they belong only to the `var` array, not to `campi_scala`.
- If a row has no CAMPO value, skip that row.

<example>
Source row: `NH3 | NH3 | 0…15 mg/Nm3 | 2 mg/Nm3 | 2.5 mg/Nm3`
Extract only:
{ "segnale": "NH3", "tag": "NH3", "campo_da": 0, "campo_a": 15 }
(the limit columns, 2 mg/Nm3 and 2.5 mg/Nm3, are ignored here)
</example>

<prohibited_behavior>
- Do NOT copy limit values into campo_da / campo_a.
- Do NOT leave the unit of measure inside campo_da / campo_a — they must be pure numbers.
- Do NOT invent a range for signals where CAMPO is missing.
</prohibited_behavior>
