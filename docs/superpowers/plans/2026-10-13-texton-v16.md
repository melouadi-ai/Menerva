> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prompt VLM v16 + 3 patch al consolidatore per TEXTON/TEXTOFF trascritti esatti dal PDF.

**Architecture:** I contratti VLM si riscrivono (v16, i v15 restano in history); il consolidatore riceve 3 patch locali con parità AST DOC↔canvas e budget paste < 33.792 byte; ogni comportamento è pinnato da test prima del codice.

**Spec:** `docs/superpowers/specs/2026-10-13-texton-esatti-v16-design.md`

## Global Constraints

- `src/` autorevole; specchi `myhydra/` byte-identici (README con sha256 aggiornati).
- Canvas: no `def`/`class`/`lambda`, output in `result` (creator legacy usa `print`, non toccare), paste < 33.792 byte, niente comprehension su locals.
- Comunicazione in italiano; prompt e codice in inglese; nodi per nome esatto; paste di file completi.
- TDD rosso→verde; suite 156 root + 81 double sempre verdi; commit per task.

## Review Focus

- Header di stato fuori catalogo → `null` + `sospetto_sottocampionamento` (test in Task 1).
- `riga` duplicata con descrizioni in conflitto → vince chi matcha, else first-wins + warning (test in Task 4).
- `"digitali_visti"` presente/assente/malformato → mai crash, chiave ignorata (test in Task 1).
- Blocchi `rows` vuoti → un solo warning `blocco_rows_vuoto` col conteggio (test in Task 6).
- Paste oltre budget → `test_canvas_copies_sotto_budget_e_standalone` rosso prima dell'incollatura (verifica in Task 6).
